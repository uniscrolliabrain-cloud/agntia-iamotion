# ORDEN PRIORITARIA: IMPLEMENTAR EL RUNTIME AHORA
La misión es escribir y ejecutar código funcional, no auditar. La inspección inicial se limita a lo indispensable para compilar y localizar contratos; máximo 10% del esfuerzo. En el primer macroturno entrega código del compilador, sampler temporal y primer componente vivo ejecutable con tests. Continúa con Blender worker real, render adapters, React runtime, partículas, infografías, tipografía, presentaciones, RAG conectado, Hono y SDK. Cada macroturno debe modificar código funcional y producir pruebas ejecutadas; no entregar macroturnos exclusivamente documentales. Los informes son subproductos de la implementación. No esperar a completar auditorías generales ni a clasificar todo el catálogo para construir los primeros vertical slices sintéticos. Resolver fallos concretos mientras se implementa. Mantener límites de autorización existentes. Esta prioridad prevalece sobre cualquier orden anterior que sugiera una campaña de auditoría previa extensa.
