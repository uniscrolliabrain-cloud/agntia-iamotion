# Laboratorio operativo previo al runtime
Primero taxonomía y carpetas de entidades, luego fichas RAG. Scripts Node reproducibles leen inventario y tarjetas, generan propuestas con evidencia y validan. GitHub Actions manual/desactivado inicialmente; sin proveedor ni secretos hasta autorización. Futuro adaptador embeddings indexa fichas versionadas; LLM recibe contexto recuperado y devuelve JSON validado, nunca modifica autoridad. Outputs separados: proposals, review, approved; solo aprobación explícita promueve. Registro JSONL por run: runId, commit, scriptVersion, input hashes, counts, unmatched, warnings, elapsedMs, status, output hashes; no prompts privados ni secretos. Replay por inputs fijados. Git público solo activos de plataforma autorizados; tenants fuera. Migración: mismos IDs, schemas y eventos a SDK/runtime, sustituir ejecutor Actions por jobs gobernados. No confundir simulación con ejecución real.
