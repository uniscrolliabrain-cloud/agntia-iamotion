# Blender production recipes — proposed
Extend P16/P17, no new runtime. Recipe schema: scene units meters, axis convention, named parts, geometry primitives, bevel segments, material refs, UV policy, lights, camera, clips, export profile. Trusted Python builder dispatches allowlisted operations; no eval or user script. Mail: rounded body, separate flap with hinge pivot, seal parented to flap; closed/open clips, no mesh intersection at sampled poses. Calendar: base, rings, page layers, page turn only if geometry supports it. Finance: ceramic base and stacked discs, stable silhouettes. Folder: shell and tab, opening motion. Each is a proposed reconstruction, not a claim about existing images.
Pipeline validate recipe -> resolve approved assets -> isolated Blender job -> save blend source -> export GLB -> inspect node/animation names, finite transforms, texture sizes, bounds -> render fixed camera contact sheet -> review. GLB interactive clips use supported transform animation; unsupported procedural shaders bake to textures or report degradation. Blender film may use richer lighting. Pin Blender version and export settings; record environment, hashes, elapsed time and failure codes. Never treat PNG as editable 3D.
Initial quality tests: silhouette at 24/48/96px, material under neutral and alternate light, pivot continuity, no clipping, static fallback, browser load and frame timing. All numerical budgets provisional.
