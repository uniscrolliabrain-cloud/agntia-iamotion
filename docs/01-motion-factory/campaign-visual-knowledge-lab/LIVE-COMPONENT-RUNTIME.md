# React delivery and property binding
Extend P31/P38/P42/P52. VisualDefinition is immutable versioned asset+spec; VisualInstance owns ephemeral props/state; host owns business data. Proposed TS interface VisualProps {definitionId,revision,state,parameters,quality,motionPolicy}; parameters validated against definition schema, unknown keys rejected. No LLM calls per frame. React adapter resolves manifest, loads resources with cancellation, reference counts shared textures/geometry, disposes on unmount. State priority disabled/reducedMotion > error/success/working > press/hover > idle; business state cannot be inferred from animation. Retarget from current pose, ignore stale revision, preserve focus. Native button semantics, text selectable, semantic infographic alternative.
Renderer selection: DOM/CSS for text/buttons, SVG for semantic diagrams, Canvas for decorative fields, WebGL for 3D/large fields. One scheduler per surface proposed, visibility and intersection pause, capped DPR, quality downgrade with hysteresis; never downgrade factual content. SSR static fallback, hydration no layout jump. Host data bindings read-only, no business actions from visual effects. Test rapid state changes, unmount during load, context loss, hidden tab, keyboard, reduced motion, multiple instances sharing resources.
