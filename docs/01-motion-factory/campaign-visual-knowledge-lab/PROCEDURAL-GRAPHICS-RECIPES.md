# Product recipes — proposed not rendered
R01 breathing constellation: seeded nodes, proximity edges, slow amplitude bounded, static fallback; semantic graph uses actual IDs, decorative graph explicitly labelled.
R02 flow field: bounded particles advected by analytic vector field, drag and lifetime; no inference of cognition from movement.
R03 orbital geometry: concentric rings and spheres, phase offsets, responsive center and radius, avoid visual overlap.
R04 magnetic surface: pointer attraction with radius/falloff and return spring; decorative only, touch fallback and reduced motion.
R05 living infographic: data nodes anchored by layout, particles along edges only when real event or explicit demo; edge flow rate not quantitative unless mapped with units.
R06 ceramic assembly: Blender named parts and clips, particles as optional web overlay, not baked into interactive asset.
R07 typography emergence: particles reveal mask around text, exact DOM text remains, no glyph distortion unless supported.
R08 cinematic button: local highlight follows pointer, bounded tilt and press; native action independent.
R09 ambient mesh: slow gradient field, depth and light parameters, no interference with contrast.
R10 presentation transition: deterministic seeded dissolve between scenes, fixed frame sampling, static cut fallback.
Each recipe: typed inputs, supported renderer, semantic vs decorative distinction, source assets, quality profiles, accessibility, golden sample frames and performance measurements. No generated shader or script execution.
