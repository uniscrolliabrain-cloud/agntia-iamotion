# Product capabilities and shared foundations
Blender Motion: geometry/material/light/camera/clip/GLB; Living Icons: state/pivot/clip/fallback; Living Infographics: graph/data/layout/edge flow; Cinematic UI: text/button/native semantics/lighting/mask; Motion Presentations: scenes/timeline/type/data/export; Living Procedural Design: particles/fields/geometry/responsive interaction. Shared Composition IR, BehaviorSpec, asset registry, renderer negotiation, RAG, evidence, jobs and certification. No separate runtimes.
Cross-product properties: intensity normalized, durationMs, easingId, paletteId, depth, lightAngleDeg, density, seed, qualityProfile, motionEnabled; expose only supported subset. Host events drive semantic states; decorative simulations independent. Visual property changes never trigger business actions. Live vs film capability distinction; static fallback for all.
First six demos: ceramic mail GLB; three-node live process; cinematic text block; native cinematic button; three-scene presentation; responsive particle constellation. Preserve initial 50 asset target and all prior research; expand catalog after demos reviewed. Proposed benchmark across phone/desktop, low/high quality, portrait/landscape, reduced motion, hidden tab, context loss. No claim of achieved quality.
