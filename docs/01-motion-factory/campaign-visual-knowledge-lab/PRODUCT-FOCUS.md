# Prioridad productiva — retorno al alcance original
Decisión del fundador: Blender motion, iconos dinámicos, infografías vivas programables, bloques de texto y botones con cualidades cinematográficas, presentaciones motion graphics y tipografía contemporánea. No editor audiovisual generalista. Mantener P01–44 como infraestructura, pero priorizar dependencias de cinco vertical slices. No ampliar fase 2 ni instalar en padre. Fuente canónica: docs/01-motion-factory/README.md, docs/ARCHITECTURE.md, src/contracts.ts (V1 actual muy reducido). Los contratos avanzados siguen siendo propuestas.
V1 icono correo: reconstrucción cerámica con cuerpo, solapa y sello; referencia visual aprobada necesaria; geometría oculta propuesta. Blender genera GLB con piezas/pivotes/clips, PNG fallback y microvídeo opcional. React controla idle/hover/press/working/success/error por props y eventos autorizados.
V2 infografía: tres nodos de proceso, enlaces y estado real o demo explícita; SVG/React, layout estable, valores exactos, transición interrumpible, accesibilidad.
V3 bloque tipográfico: título/subtítulo con máscara, stagger por palabra, profundidad sutil y composición responsive; texto DOM seleccionable, reduced motion.
V4 botón cinematográfico: superficie cerámica, highlight direccional, elevación, borde y respuesta press; acción nativa independiente de animación, teclado/foco/disabled/loading, sin falso éxito.
V5 presentación: tres escenas con títulos, gráficos y activo 3D reutilizado, navegación manual y timeline exportable; 16:9 y 9:16 mediante reflow; no editor multipista generalista.
