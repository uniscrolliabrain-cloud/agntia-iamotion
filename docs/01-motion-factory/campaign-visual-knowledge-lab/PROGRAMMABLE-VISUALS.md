# Contrato de componente programable
VisualComponentSpec {id,revision,kind,assetRefs,propertySchema,defaults,stateGraph,bindings,renderVariants,fallback,accessibility,budget}. Property definitions typed number/color/enum/boolean/vector with unit, min/max, animatable, allowed states; reject unknown keys. Public React props distinct from internal shader parameters. Proposed shared props intensity, durationMs, easingId, paletteId, elevation, depth, lightAngleDeg, motionEnabled, state. Each component exposes only supported subset. No raw CSS, shader, Python or event handler from LLM. Host maps trusted events to state; no action authority. State transitions cancel/retarget; disabled and reduced motion override decoration. Button uses native button semantics; label stays readable; click not delayed by animation. Text block uses semantic heading/paragraph, no per-letter accessibility duplication. Infographic binds immutable DatasetSnapshot, stable IDs, accessible alternative. Asset delivery manifest pins hashes and versions; runtime component has no LLM call. Film variants may use more expensive lighting but never imply live interactivity.
