# Animation principles and interchange
Primary research: John Lasseter, SIGGRAPH 1987, https://users.cs.northwestern.edu/~animation/Lasseter_1987.pdf. Normative interchange: https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html . Translate timing/spacing, arcs, anticipation and overlap into candidate tracks, not mandatory UI effects. Maintain separate cinematic and transactional profiles; interactive motion must be cancelable. glTF adapter maps baseColor factors in linear space, sRGB color texture, linear metallic/roughness texture (G roughness, B metallic); alpha coverage distinct from emission; explicit capability report for unavailable extensions. Test channel mapping using synthetic texture and round-trip validation. No implementation now. ACES and MaterialX remain research backlog, not verified here.
