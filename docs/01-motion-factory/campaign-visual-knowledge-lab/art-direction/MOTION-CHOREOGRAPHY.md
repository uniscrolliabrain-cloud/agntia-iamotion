# Motion grammar and choreography
Apple HIG and WCAG 2.3.3 inform UI motion policy. Classical animation concepts proposed for study: timing, spacing, anticipation, staging, arcs, follow-through, overlap, slow-in/out, secondary action, squash/stretch, exaggeration, appeal; distinguish animation of expressive character from utilitarian UI. Motion intent enum feedback, orientation, hierarchy, transition, status, decorative. Track normalized time with units and interpolation. Cubic Bezier x controls within [0,1]; spring mass/stiffness positive, damping nonnegative, bounded settle time; no arbitrary expressions. Choreography DAG supports sequence, parallel, stagger, shared element continuity; state changes interrupt and retarget from current value; avoid input lock. Initial experimental profiles subtle idle, hover, press, processing, success, failure; no fabricated cognitive benefits. Reduced-motion static or non-motion feedback, user preference wins; test cancellation, rapid input, background tab, layout shift and frame budget. Peripheral/immersive motion warrants separate comfort review; do not port film camera motion blindly to UI.
