# Quality benchmark — aspirational, not achieved
Use own approved assets and synthetic fixtures, not copied studio imagery. Benchmark dimensions: semantic recognition, silhouette at target size, brand consistency, geometry plausibility, material response, light coherence, color pipeline, temporal continuity, UX purpose, accessibility, technical delivery. Review scale 0 absent,1 severe defect,2 major revision,3 adequate,4 polished,5 exceptional; independent reviewers with evidence and disagreement retained. Hard veto: unauthorized asset, broken references, accessibility failure, unsafe content, unsupported capability. Compare candidate vs original blind where practical; fixed camera/light for material comparisons, fixed viewport/device for motion. Report frame time percentiles, dropped frames, file size, first paint, decoded memory where measurable; no universal budget before device baselines. Golden examples: launcher ceramic envelope, automation node, editorial photograph; actual source IDs resolved at execution, not invented. No global 'world class' score without external comparative evaluation.
