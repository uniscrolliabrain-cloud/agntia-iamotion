# Composición gráfica temporal
Taxonomía: editorial title, lower third, opener, end card, logo reveal, kinetic poster, explainer, diagram, infographic, data story, product showcase, HUD decorativo, transition, chapter marker. Capas text, vector, raster, group, mask, chart, camera; z-order explícito. CompositionSpec {version,id,revision,viewport,frameRate:{num,den},durationTicks,timebase,background,layers,tracks,markers,bindings,accessibility}. Layer {id,parentId,kind,assetRef?,textRef?,transform,opacity,blendMode,maskRef?,inTick,outTick}. Validar DAG, referencias y presupuesto. Tiempo entero, intervalo [in,out), frame n evaluado en n/fps racional; evitar acumulación delta por frame. Matrices de transformación en orden documentado; coordenadas de pantalla y mundo distintas. Layout responsive por constraints, safe areas y breakpoints; no escalar texto indiscriminadamente. Gestalt: proximidad, similitud, continuidad, figura/fondo, agrupación; jerarquía, ritmo, alineación, contraste, whitespace. Cada técnica tiene usos y contraejemplos. Secuencia: briefing -> storyboard -> layout -> timeline -> checks -> preview -> review -> export. Sin arbitrariedad CSS/JS ni shaders no autorizados.
