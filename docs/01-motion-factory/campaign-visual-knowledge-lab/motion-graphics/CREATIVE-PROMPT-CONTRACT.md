# Creative director prompt contract
Input: brief, target surface live/film, audience, locale, exactTextLocks[], datasetRefs[], allowedAssetIds[], fontRefs[], styleFamily, rendererCapabilities, durationBudget, accessibilityPolicy, evidenceCards. Output: status proposed/insufficient_context/unsupported, storyboard beats, composition candidate, techniqueRefs, rationale, unknowns, requiredApprovals. LLM must not rewrite locked strings, invent data, request arbitrary code, assume fonts or capabilities, or grant rights. Storyboard first, deterministic layout second, timeline third; validate each boundary. Creative alternatives differ in choreography not factual content. Reviewer returns issue codes TEXT_CHANGED, DATA_UNBOUND, GLYPH_MISSING, OVERFLOW, UNSUPPORTED_FEATURE, RIGHTS_PENDING, MOTION_POLICY, TIMING_UNREADABLE. No self-approval. Integrate P24/P25 and P43. Prompt text and schemas to be implemented after core contracts.
