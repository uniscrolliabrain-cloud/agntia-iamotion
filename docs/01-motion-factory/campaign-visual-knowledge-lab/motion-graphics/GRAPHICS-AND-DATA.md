# Gráficos, formas y narrativa de datos
ShapeSpec: rect/ellipse/line/path/polygon, fill/stroke, gradient stops, corner radius, dash, trim, mask, transform. Path morph requiere correspondencia de contornos; incompatible -> crossfade o transición explícita. Gradientes en espacio declarado; colores interpolados coherentemente. Procedural motifs: orbit, grid, particles bounded, connection paths, signal pulse, abstract geometry, flow map; seed fijada y límites de partículas. ChartSpec {datasetRef,revision,units,encoding,domain,scale,baseline,labels,transition}; valores reales del host, nunca del LLM. No barras truncadas engañosas, no animar cifras inventadas, no suavizar series para ocultar cambios. Mostrar valor exacto accesible y estado synthetic/live claramente. Transiciones enter/update/exit por ID estable; conservar ejes comparables o declarar cambio. Narrativa: setup, focus, evidence, conclusion, hold. En diagramas operativos distinguir flujo decorativo de estado real; eventos solo del runtime. No simular actividad de agentes. Exportar descripción textual y tabla alternativa.
