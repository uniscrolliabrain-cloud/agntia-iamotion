# Tipografía cinética
TextSpec {id,sourceText,locale,direction,writingMode,fontRef,fallbackRefs,style,layout,semanticSpans,animationGroups,accessibilityText}. Unicode grapheme clusters no equivalen a codepoints ni glyphs; segmentación por grafema/palabra/línea y shaping por fuente/script; preservar ligaduras, marcas combinantes, bidi, árabe y emoji. No dividir shaping run si rompe escritura. Texto editable permanece fuente de verdad aunque se rasterice. FontRef hash, familia, versión, licencia, cobertura, ejes y límites. Esperar font loading antes de medir/exportar, fallback explícito. Métricas ascent/descent/baseline/advance, kerning/tracking/leading, cap height, x-height, line break, optical alignment. Ejes variables wght/wdth/slnt/ital/opsz solo si fuente los soporta; validar min/max y layout shift. Unidades px/em normalizadas. Gramática: fade, rise, slide, mask reveal, wipe, stagger, word emphasis, tracking settle, variable-axis morph, baseline wave, scale settle, typewriter, counter, path-follow, glyph morph solo con contornos compatibles. Ocultar decoraciones a lector de pantalla, conservar texto completo accesible, no anunciar cada letra; captions sincronizados conservan lectura y pausas. No deformar palabras legales, dinero ni cifras operativas. UI: movimiento breve y no bloqueante; vídeo: mayor expresividad con tiempo de lectura y contraste evaluados. No atribuir emoción universal a una técnica.
