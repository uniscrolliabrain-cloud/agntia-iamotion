# M7 — Composición, gráficos y tipografía (P33–38)
Plan documental. Dependencias P03, P13, P14, P17; no instalar motores.
## P33 Composition IR
A: composition.ts strict discriminated layers; IDs únicos, viewport positive integer, rational fps reduced, timebase positive integer, ticks safe integers; max 256 layers/4096 tracks provisional. B: validate graph including parent, mask and subcomposition edges; stable topological order; interval [in,out); frame time rational n*den*timebase/num, compare via integer arithmetic, no rounding drift. C: parse JSON only, canonical hash and schema export. D: cycle across mask+parent, duplicate ID, 30000/1001 fps, exact out boundary, overflow. E: BehaviorSpec adapter maps units explicitly; no silent coercion.
## P34 Shape IR
A: shapes.ts union rect/ellipse/line/polygon/path; finite coordinates, bounded commands M/L/C/Q/Z, fill/stroke/gradient, mask reference. B: normalize path commands; morph only matching topology and command arity; otherwise explicit crossfade candidate. C: SVG serializer escapes text and attributes, no foreignObject, scripts or URLs; renderer adapter later. D: malformed path, NaN, negative radius, gradient stop order, incompatible contours. E: shape capability manifest and golden SVG fixtures.
## P35 Layout
A: layout.ts constraints anchor, min/max, padding, alignment, safe area, breakpoint; no arbitrary CSS. B: resolve parent box then children, measure text before layout, detect unsatisfiable constraints; overflow policy wrap/reflow/reject, no silent crop. C: viewport presets 1920x1080,1080x1920,1080x1080 and responsive host viewport; presets provisional. D: long Spanish title, narrow screen, RTL, missing font, conflicting constraints. E: emit bounds report per layer and safe-area violations.
## P36 Font registry
A: fonts.ts FontRef hash, license evidence, family/style, coverage, axes min/default/max, permitted embedding. B: resolve exact face and fallback chain per script; verify axes and glyph coverage; unknown rights deny export. C: local hash-addressed font store, no remote font downloads; wait for readiness with timeout. D: absent font, wrong hash, unsupported axis, missing glyph, license pending. E: record resolved font hashes in render manifest.
## P37 Text shaping
A: text.ts sourceText immutable, locale, direction auto/ltr/rtl, writing mode, spans by UTF16 offsets with grapheme-boundary validation; shaping port returns glyph IDs, clusters, advances, positions, run direction. B: segment graphemes via Intl.Segmenter, bidi and shaping delegated to qualified adapter; preserve logical-to-visual mapping; never assume one glyph per grapheme. C: browser native layout for live, candidate HarfBuzz adapter for offline; no fake glyph positions. D: e+combining accent, emoji family ZWJ, Arabic joining, fi ligature, mixed RTL numbers, line wrapping. E: exact text accessibility mirror; font/engine version in receipt.
## P38 Type behaviors
A: behaviors.ts discriminated technique parameters, target group word/grapheme/run/line, duration, delay, fallback. B: expand groups into tracks only where shaping safe; mask reveal works on whole run; glyph morph requires verified contours; preserve original text. C: renderer negotiation, no arbitrary CSS. D: typewriter must not expose partial legal amount as final; reduced motion shows full text; interrupted reveal restores readable state. E: integrate P13 and P39, record unsupported technique.
