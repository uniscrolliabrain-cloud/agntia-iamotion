# M8 — Timeline, data, audiovisual y certificación (P39–44)
## P39 sampler
A: sample.ts pure sample(composition,tickRational) -> evaluated scene; typed interpolation and replace/add. B: binary search keyframes; clamp outside range by explicit fill policy; cubic Bezier invert x by bounded bisection; spring analytic or fixed-step versioned solver; no wall clock. C: live clock adapter separate from offline frame iterator; cancellation retarget captures current state. D: seek order invariance, fractional fps, exact boundaries, parallel conflict, interruption. E: same IR to web and film, compare numeric samples.
## P40 data graphics
A: data.ts DatasetSnapshot {id,revision,scope,rows,units,source,synthetic}; encoding allowlist; binding references field IDs. B: validate units/domain, stable enter/update/exit IDs, compute chart geometry from host values; never accept LLM numeric replacements. C: host read port only, no external fetch. D: stale revision, missing value, zero/negative domain, misleading truncated bar, synthetic label. E: accessible table and exact value, runtime event provenance.
## P41 cues
A: cues.ts AudioCue and CaptionCue with integer ticks, license, locale, gain and overlap policy. B: validate intervals and fades, caption text exact, explicit overlapping speaker handling, no invented timing. C: audio adapter optional, mute UI, export mux future. D: negative tick, end beyond composition, overlapping forbidden cue, unlicensed audio, missing timing. E: silent fallback and caption track report.
## P42 capabilities
A: capabilities.ts feature IDs and adapter version, supported/degraded/unsupported, degradation policy. B: collect required features recursively; negotiate before rendering; deny if mandatory feature unavailable, optional fallback explicit. C: isolated render job manifest with asset/font hashes, no network or secrets, fixed engine versions. D: unsupported mask, variable axis, blend, alpha, unsafe URI, timeout. E: renderer result includes actual capability report and artifact hashes; no fake preview.
## P43 knowledge and prompts
A: technique cards term/definition/parameters/prerequisites/contraindications/evidence, proposal schema composition+text locks. B: retrieve facets by intent, preserve exact supplied text and numbers, validate references and capabilities. C: existing P24/P25 ports; no new provider. D: changed KPI, hallucinated font, injected instructions, missing source, unsupported glyph morph. E: cards compile via P18; proposals staged, never approved automatically.
## P44 benchmarks
A: benchmark manifest with fixture ID, viewport, fps, input hashes, expected assertions, renderer version. B: sample fixed frames, measure bounds, text equality, glyph coverage, frame timing and bytes; compare image differences only in pinned environment. C: human review form with evidence and disagreement; no invented scores. D: deliberate clipping, wrong text, missing glyph, dropped frame, inaccessible fallback. E: report baseline vs candidate, hard vetoes, reproducibility and limitations.
