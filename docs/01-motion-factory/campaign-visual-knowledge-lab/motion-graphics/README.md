# Motion Graphics & Kinetic Typography — extensión documental
Dos especialidades sobre el mismo compilador temporal, no dos runtimes. Referencias consultadas: CMU UIST 2002 https://www.cs.cmu.edu/~johnny/academic/KT_Engine_UIST2002.pdf ; ECCV 2024 https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/05000.pdf ; ICCV 2025 https://openaccess.thecvf.com/content/ICCV2025/papers/Liu_Dynamic_Typography_Bringing_Text_to_Life_via_Video_Diffusion_Prior_ICCV_2025_paper.pdf ; W3C CSS Font Loading https://www.w3.org/TR/css-font-loading/ y CSS Fonts 4 https://www.w3.org/TR/css-fonts-4/ (borradores). CMU inspira manipulación tipográfica jerárquica; papers de difusión inspiran separación entre semántica, apariencia y movimiento, no adopción inmediata de modelos. Prioridad texto exacto y editable, composición determinista. Motion Canvas, Motion, HyperFrames, Three.js, Blender y Remotion siguen siendo candidatos previamente identificados, no dependencias instaladas ni auditadas en este turno. Fase 1 únicamente.
