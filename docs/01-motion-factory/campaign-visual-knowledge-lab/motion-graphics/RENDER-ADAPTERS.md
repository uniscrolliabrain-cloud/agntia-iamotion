# Adaptadores y elección tecnológica
Capability matrix propuesta: web DOM/CSS/Motion para UI accesible e interrumpible; SVG para formas y máscaras; Canvas/Motion Canvas candidato para composiciones temporales; HyperFrames candidato HTML render offline; Three.js para 3D ligero; Blender para secuencias 3D; FFmpeg para mux/encode; Remotion alternativa a evaluar, no asumir licencia. Un IR declarativo común, adaptadores reportan supported/degraded/unsupported. No ejecutar HTML/JS libre del LLM. Fonts y assets fijados por hash, no URL externa, render sandbox sin credenciales/red. Frame export determinista dentro de entorno fijado; diferencias GPU/font/platform reportadas, no prometer igualdad bit a bit entre máquinas. Web preview y export comparados por landmarks/snapshot visual; fallback estático obligatorio. Revisar licencia, mantenimiento, API y benchmark antes de seleccionar o instalar cada dependencia.
