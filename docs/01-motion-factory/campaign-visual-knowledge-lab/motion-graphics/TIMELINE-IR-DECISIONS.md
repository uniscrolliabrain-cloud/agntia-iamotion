# Canonical timeline decisions
P13 BehaviorSpec remains reusable primitive, P33 CompositionSpec owns scene graph, P39 owns evaluation; no parallel animation runtime. Timebase initial 240000 ticks/sec proposed, rational frame sampling handles rates not dividing timebase. Tick values safe integers, rational comparisons via BigInt internally; JSON stores integer numerator/denominator within validated bounds or decimal strings if necessary, choose one representation in implementation. Transform order proposed T(position)*T(pivot)*R*S*T(-pivot), column vectors; parent world matrix multiplies child local. 2D y down, 3D coordinate adapter explicit. Opacity parent multiplication, z-order stable by declared index. Masks depend on referenced geometry, not arbitrary code. Interpolation: discrete for enum/text, linear numeric, color in declared linear space, rotation shortest arc only if explicitly chosen; no interpolation of business values as factual text. State transitions cancelable; export samples fixed timeline. Loop count finite for export, live idle policy separate. Reduced motion is alternate composition or static terminal state, not merely faster animation. Unknown feature fail closed or documented optional fallback.
