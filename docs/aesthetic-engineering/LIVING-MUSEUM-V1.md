# Agntia Living Museum V1 — proposed design
Status: design only; no production installation or implementation authorization.
## Purpose
A persistent navigable spatial projection of authorized enterprise knowledge, operations and learning. Not a separate business runtime, not a social metaverse. Agntia Demo is the first synthetic fixture. Desktop and mobile browser, no headset required.
## Visual canon
Ivory ceramic, violet enamel, champagne gold, warm paper, restrained optical effects, organic architecture. Reuse Agntia Motion engines and approved assets; existing demo is not the artistic ceiling. Stable landmarks and optional reduced motion. Three.js initial renderer; Blender for approved sculptures.
## V1 scope
Atrium with three galleries: operations (synthetic SOP graph and Kanban), finance (exact synthetic values and sculptural charts), knowledge/learning (concepts, documents, guided lesson). A fourth engineering gallery is a subsequent slice. Free orbit/pan/zoom, click-to-focus, semantic zoom, guided tour, accessible 2D equivalent. No real writes, multiplayer, XR, procedural unlimited worlds or production tenant installation.
## Authority
Host provides scoped served ViewSpec projection with revision and stable IDs. Spatial adapter never queries business databases directly. LLM proposes tour and layout only; deterministic validation checks allowed IDs, bounds and capability. No unauthorized data in geometry, labels, caches or telemetry. Read-only V1; later actions via host intent/approval.
## Proposed contracts
SpatialViewSpec: schemaVersion, scope, revision, rooms, entities, relations, exhibits, permissions. Entity: stable ID, sourceRef, kind, label, semantic parent, approved visualRef, exact value optional. SpatialLayoutSpec: room bounds, stable anchors, positions, camera bookmarks, relation routes. TourSpec: ordered steps, entity refs, narration refs, camera bookmarks, optional recall prompt. LearningSession: user-scoped concept IDs, attempts, outcomes, next review; no biometric inference. All schemas bounded and strict. No executable code from LLM.
## Layout and navigation
Deterministic room assignment by semantic parent; stable anchor map across revisions; new entities occupy free slots; explicit relayout only. Orthographic overview and perspective room camera; collision-free waypoint paths with bounded velocity, reduced-motion cut alternative. Semantic levels enterprise, room, exhibit, source detail. Preserve browser back and deep links. Keyboard, touch, text search, 2D accessible equivalent. Relation visibility on demand.
## Learning
Orientation, explanation, observation, prediction, manipulation in isolated synthetic sandbox, active recall, transfer task, spaced revisit. Persistent spatial anchors support memory; no claim of universal learning benefit. Guided narration optional. Compare learning against equivalent 2D lesson with delayed recall and transfer, not engagement alone.
## Implementation slices
M13 contracts, synthetic fixture, scoped validation, stable topology and layout.
M14 Three.js scene, camera controls, semantic zoom, picking, keyboard/touch and 2D fallback.
M15 approved sculptures, ambient fields, optical materials, LOD and disposal.
M16 operations/finance exhibits, exact data tables, event replay in synthetic scope.
M17 knowledge gallery, tour compiler, recall and sandbox lesson, explicit learning session.
M18 constructor proposal validator, integration adapters, performance and accessibility gates.
## Acceptance
Stable IDs and anchors across revisions; no cross-scope refs; exact metrics and source details; no real mutation; deterministic replay and tour seek; reduced motion and keyboard access; bounded scene budgets; mobile fallback. Proposed performance targets desktop 60 fps/mobile 30 fps on named test devices, measured not assumed. Visual acceptance by founder; learning efficacy requires evaluation. No merge or parent install before approval.
