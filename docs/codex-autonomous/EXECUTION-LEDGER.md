# Ledger template
Create machine-readable ledger in execution branch, not fabricated here. Fields area, patchset, unit, dependencies, status pending/running/passed/failed/blocked, sourceDocs, files, tests[{command,exitCode,receipt}], artifacts[{path,sha256}], baseline, scoreEvidence, blocker, decision, commit. Seed P01–52 × A–E from existing microspecs, plus explicit gaps discovered. Record initial HEAD and actual branch. Maintain HANDOFF.md after each macroturn. Report ten area scores with gate evidence, no invented tests. Use local logs without secrets; generated heavy artifacts outside public Git unless rights and size approved. Release candidate manifest includes tool versions, dependency lock hash, asset snapshot, artifact hashes, known limitations and rollback instructions.
