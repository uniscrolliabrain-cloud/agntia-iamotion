# Agntia visual library

Single library for phase 1. Source: uniscrolliabrain-cloud/agente. Never modify source. Inventory main, ui-lab and ui-lab-pro separately; other branches require explicit selection. Inspect all apps including ui-lab, Mi Empresa and normal app. Preserve SHA-256, original paths, source commit and all aliases. Do not publish private/customer assets or unknown-rights assets until reviewed.

Each asset has a JSON RAG card: id, sha256, original paths and refs, MIME, dimensions, component references with line evidence, semantic title, slug, alt text, description, keywords, visual style, intended UX role, motion candidates, rights, audit status and confidence. Separate observed facts from inference. Never claim visual inspection from filename alone. Semantic filenames are assigned after review, not in source. Duplicate bytes share an asset ID. Store reviewed assets in assets/, cards in cards/, candidate inventory in inventory/. SEO fields are descriptive, not keyword stuffing. Generate JSONL for retrieval after review. No tenant data in this public repository.

Import is staged: inventory, context audit, visual review, approval, publish. No automatic promotion of unreviewed images.
