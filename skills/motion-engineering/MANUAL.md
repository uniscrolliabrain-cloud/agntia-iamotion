# Operator manual
Current executable SDK: createAestheticSession(adapter, policy, lockedText, allowedFeatures). Adapter implements capabilities, mount, draw, dispose. Call load('scene'|'film', input), seek(ms), getSnapshot(), subscribe(listener), dispose(). Search retrieves experimental techniques, not authorization. Scene compiler validates layer IDs, intervals, feature availability, particle/vertex/sculpture budgets and locked text. A host must supply the policy and adapter.
Future editor: target selector, layer tree, timeline, keyframes, inspector, mixer, curves, preview, history and export. These are planned, not active. All controls and agent tools must edit the same typed document. Preview uses local fixtures; publishing requires explicit review. Manual generated section is returned by buildMotionKnowledge(version, hostManifest). No host manifest means no active capabilities.
Troubleshooting: invalid interval → correct bounds; unavailable feature → select supported adapter; budget error → reduce complexity; text lock → use authorized text reference; version mismatch → align SDK and manifest. Dispose sessions on unmount.
