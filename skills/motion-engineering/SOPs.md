# SOP catalog
Every procedure requires target revision, capability status, policy, fixture, evidence and rollback reference. Stop if unavailable.
01 Intent: translate prompt into observable behavior and acceptance criteria.
02 Audit: inspect target source, states, callbacks and tokens.
03 Canon: retrieve approved references and record provenance.
04 Reuse: query registry; distinguish implemented from active.
05 Scene: validate strict scene input, compile and inspect layers.
06 Timeline: bound intervals; seek start, middle, end.
07 Keyframes: planned editor; validate interpolation before use.
08 Curves: planned inspector; require bounded interruption-safe physics.
09 Cascade: identify stable order and preserve interaction.
10 Transition: preserve focus and navigation state.
11 Opacity: preserve essential contrast; never hide actionable state.
12 Attention: prioritize explicit user focus, not inferred emotion.
13 Spatial: stable anchors, keyboard and 2D fallback.
14 Optical: bound blur and respect reduced motion.
15 Coordination: check overlap and resource budgets.
16 Typography: use locked text, preserve reading order.
17 Analytics: exact values and accessible equivalent.
18 Icons: reuse approved material and silhouette.
19 Blender: validate recipe; isolate rendering.
20 Particles: enforce count and disposal.
21 React: adapter lifecycle; no global mutation.
22 Fixtures: synthetic only, preserve semantic values.
23 Algorithm: pure typed input/output; deterministic tests.
24 Export: versioned declarative spec, no arbitrary code.
25 Patch: isolated UI Lab change, diff and rollback.
26 Performance: measure named devices, no unsupported FPS claims.
27 Accessibility: keyboard, contrast, reduced motion.
28 Comparison: capture same viewport and fixture before/after.
29 Publish: verify CI, review, pin version and commit.
30 Rollback: restore previous pinned artifact and verify.
These are initial procedures, not certification of all tools.
